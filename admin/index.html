GitHub 연결 설정

수정 내용을 저장하려면 연구실 저장소에 접근할 수 있는 관리자의 GitHub 토큰이 필요합니다. 토큰은 이 페이지를 연 동안만 사용하며 저장하지 않습니다.

처음 연결하는 방법
  1. 연구실 조직에 접근할 수 있는 본인 계정으로 GitHub에 로그인합니다.
  2. Fine-grained token 만들기 ↗에서 만료일을 정하고 Resource owner를 elsdr-lab으로 선택합니다.
  3. Only select repositories에서 elsdr-lab.github.io만 선택합니다.
  4. Repository permissions → Contents: Read and write만 허용합니다. 조직 승인이 필요하면 Owner가 승인해야 합니다.
  5. 발급된 토큰을 위 칸에 붙여넣습니다. 비밀번호나 토큰을 채팅에 보내지 마세요.

GitHub 연결은 이 페이지와 GitHub API 사이에서 이루어집니다. 공개 홈페이지에는 별도 비밀번호가 생기지 않으며, 수정 권한은 GitHub가 확인합니다.
